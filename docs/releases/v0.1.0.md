## AhaKey Runtime v0.1.0

首个独立 Rust Runtime 版本，供 AhaKey Studio 和第三方桌面应用通过本机 WebSocket 接入 AhaKey X1。

### 已实现

- **设备连接**：BLE 发现、连接、状态事件、命令队列、断线重连与会话恢复。
- **配置读写**：四种模式、快捷键、宏、禁用键、ASCII 按键描述、状态灯效与全局亮度；支持独立改键。
- **新固件读回**：以 `Fireware-harness` 分支为协议基准，通过 `0x9F` 识别 catalog，使用 `0x87` / `0x88` 读取配置；连接、重连和进程重启后自动采集，两次一致后提供读回结果。
- **屏幕资源**：通过 WebSocket 上传图片/GIF，Runtime 完成解码、RGB565 转换和设备传输，并报告操作进度。
- **应用接口**：15 个 JSON-RPC 方法、本机动态端口发现、token 认证、快照与事件订阅、持久化操作及幂等恢复。
- **开发联调**：`--mock` 无设备模拟器；macOS 附带输入监听 helper，通过 `--input-monitor` 启用。

### 下载与安装

| 系统 | 下载文件 | 安装和启动 |
| --- | --- | --- |
| macOS Apple Silicon | `aarch64-apple-darwin.dmg` | 打开 DMG，将 **AhaKey Runtime.app** 拖入“应用程序”，然后打开 |
| macOS Intel | `x86_64-apple-darwin.dmg` | 同上，需要 macOS 13 或更新版本 |
| Windows x64 | `x86_64-pc-windows-msvc.exe` | 运行安装向导，再从开始菜单启动 **AhaKey Runtime** |
| Ubuntu / Debian x64 | `x86_64-unknown-linux-gnu.deb` | `sudo apt install ./ahakey-runtime-*.deb`，然后执行 `ahakey-runtime` |

文件名均以 `ahakey-runtime-v0.1.0-` 开头。macOS 最低 13；Windows 最低 10；Linux 以 Ubuntu 22.04 构建，需要 glibc 2.35+，`apt` 会安装 BlueZ、D-Bus 等依赖。

Runtime 是后台服务，没有设置窗口。macOS 打开后在后台运行，可在“活动监视器”退出；Windows 从开始菜单打开控制台，关闭窗口或按 Ctrl+C 退出；Linux 在终端运行，按 Ctrl+C 退出。安装程序不设置开机自启。

开发应用时读取 `discovery.json` 中的实际端口和 token。完整用法见 [WebSocket 接口参考](https://github.com/AhakeyAI/ahakey-runtime-rust/blob/v0.1.0/docs/websocket-api.md)、[OLED 上传接口](https://github.com/AhakeyAI/ahakey-runtime-rust/blob/v0.1.0/docs/oled-api.md) 和 [改键接口](https://github.com/AhakeyAI/ahakey-runtime-rust/blob/v0.1.0/docs/keymap-api.md)。

### 当前限制

- macOS 尚无 Developer ID 签名和公证，Windows 安装程序尚无代码签名，首次打开可能被系统拦截。
- 仅 macOS 提供原生输入监听 helper，启用后需要授予“输入监控”权限。
- BLE 长通知分片重组仍待补齐；设备 MTU 较小时，catalog 或配置读回可能失败。
- AI、设备预览、独立保存、资源清理及部分设备控制命令尚未全部开放。
- 自动检查覆盖构建、安装包内容、模拟启动和退出；真机蓝牙、输入权限及断电持久化仍需设备验收。
